关键改进
================================================================================

问题: 
  LLM API调用缺少系统消息（system role），导致缺乏API层面的上下文指导

修复:
  在所有API调用中添加明确的系统消息，包含5大核心原则

  修复前: messages: [{ role: 'user', content: prompt }]
  修复后: messages: [
            { role: 'system', content: '5大核心原则指导' },
            { role: 'user', content: '完整上下文信息' }
          ]

5大核心原则:
  1. 上下文理解 - 充分理解讨论历史、工作流背景、当前阶段
  2. 连贯回应 - 直接引用或回应前面角色的观点
  3. 角色一致性 - 保持角色特征和专业立场
  4. 内容质量 - 避免重复已讨论观点
  5. 决策支持 - 在决策阶段提供明确建议
